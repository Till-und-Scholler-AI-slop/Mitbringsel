# Live-Einkaufsliste (Go + Vue)

Web-App für digitale Einkaufslisten, die in Echtzeit zwischen mehreren Personen synchronisiert wird, auch offline nutzbar und als PWA installierbar. Backend in Go, Frontend in Vue 3 mit TypeScript, Datenbank PostgreSQL.

Die vollständige Dokumentation liegt in [docs/](docs/README.md).
